**Why the removals matter**
- *Pax Christi* is a Suffolk DSS-contracted emergency shelter for men in Port Jefferson [S41]. The draft presented fee-to-savings as an **existing local model to replicate**. The final turned it into three generic **pilots** (G1-Y25-02, G3-Y25-01b, G4-Y25-07). If a local program already does this, the final loses the evidence base and adds duplication. (A public description of the savings program could not be found, so confirm with the program before citing it.)
- *Survey counts* show that 72% of responses came from library staff and homeless-system partners, with 4 responses from elected officials, philanthropy and law enforcement combined. Readers need that to judge how representative the input was (REVIEW §5.4).

## 3. Takeaway for the next revision

The community round added partners (libraries, PHAs, DSS) and three new steps, but **no one checked the numbers**. For v1.1 and the annual update, add a short data-verification step before Board approval: one person checks each figure against its source and records it in a data dictionary.
